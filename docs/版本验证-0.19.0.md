## 解释边界

三档缓存减少普通重复观察的IO与返回，不直接控制正在生成的桌面模型。CLI续接仍可能带原上下文；本版未建立完整控制／业务费用账本，不承诺固定节费比例。

审批升级不表示用户接管了代码；保留人工待办不表示旧钩子仍能接收批准。旧记录无法可靠重建的等待时间不追溯扣除。

子代理系统包装的兼容识别不是消息来源的密码学认证；普通引用保留人类输入保护。游标修复需显式确认且只针对识别出的通知边界，不改变原控制权或重发任务。

原桌面窗口即时同步、远程Orca、长期多主控并发仍未完成实机验收。
