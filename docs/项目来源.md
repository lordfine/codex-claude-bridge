# 项目来源

本项目采用独立仓库与全新提交历史，不是 GitHub fork。

基础源码来自作者在 `claude-plugin-codex` 中维护的 0.16.0 版本，该版本基于 [xavierchoi/claude-plugin-codex](https://github.com/xavierchoi/claude-plugin-codex) 开发。协作方向受到 [openai/codex-plugin-cc](https://github.com/openai/codex-plugin-cc) 启发。

整理版本移除了废弃的短咨询实现、对应测试、多语言重复说明、开发问答、临时实机验证脚本与机器专用记录。保留当前公开工具、功能回归与必要许可声明，不把历史内容复制到新提交历史。

原生托管、Orca 和事件续接的范围保持明确区分。新仓库身份不表示所有代码均为重新编写；沿用源码的 MIT 版权与许可文本见 [LICENSE](../LICENSE)。
