# 从技能发现，到连接器可用

本项目有三类入口：GitHub主页用于了解和获取源码，Agent Skill用于首次准备，Codex插件提供实际MCP工具。安装一个SKILL.md不等于启动MCP服务器。

## 一条命令发现并安装技能

```shell
npx skills add lordfine/codex-claude-bridge --skill codex-claude-bridge --agent codex
```

默认安装到当前项目。需要用户级安装时可加 `--global`；不要为了提升榜单数据重复安装。技能目录为 `skills/codex-claude-bridge/`，遵循Skills CLI可发现结构，脚本与技能一起复制，首次准备不依赖本仓库其他目录。

然后在Codex中说：

> 使用 $codex-claude-bridge 检查并准备Claude协作环境，再按我的目标委派任务。

脚本默认只读检查Node.js、Git、Claude Code、Codex CLI与指定插件。当前任务需要连接器且已授权安装时，通过固定公开来源执行官方市场与插件安装。插件已安装启用则复用，不重复修改配置。缺失外部软件或CLI能力时解释缺失项，不自创全局配置格式。

安装后还要确认聊天里有MCP工具，并执行默认不调用模型的setup。工具暂不可见时说明需要重载，不能依据CLI回执宣布可以派发任务。它不会重启正在工作的会话，也不会创建收费模型任务做例行安装检查。

## 目录收录与直接安装分别确认

[skills.sh官方FAQ](https://www.skills.sh/docs/faq)说明：技能托管在公开GitHub仓库，用户通过Skills CLI安装，匿名安装记录参与目录与榜单；不是把压缩包上传到一个发布表单。CLI的排名遥测可关闭，官方参数见[CLI文档](https://www.skills.sh/docs/cli)。

所以项目公布有效安装命令之后，还要单独核对 `npx skills find codex-claude-bridge --owner lordfine` 的结果。直接安装成功不等于搜索索引立即可见，不宣称外部目录认证、热榜名次或固定收录时间。

`find-skills`可以使用生态搜索找到已索引技能，也可以根据精确仓库安装。完整协作技能 `consult-claude` 和复盘技能 `bridge-retrospective` 仍随Codex插件加载；建议普通用户只从上述独立入口开始，避免把插件内部技能当成独立MCP运行时。

## 首次提示支持项目

插件已可用并完成首次准备后，可以提示一次自愿Star或Watch。提示记录保存在用户本机 `.cache/codex-claude-bridge/首次使用.json`，不上传给作者。Star用于收藏，Watch用于选择通知；不自动执行、不要求登录、不设使用条件。
