# Claude 协作桥接术语

本术语表用于区分执行、交付、接管与验收，避免把不同状态混成一个“完成”。

## 会话与归属

**主控**：负责目标、阶段决策与验收的 Codex 任务。主控身份随任务保留，不由桌面窗口数量决定。

**执行会话**：在指定工作区工作的一个 Claude Code 主会话，可采用原生托管或 Orca 接入。

**执行线**：某项工作的执行归属，包含执行者、会话、工作区和已交付版本。Codex 接手实现后形成自己的执行归属，不能描述成原 Claude 窗口已推进。

**人类输入**：实际由用户发给执行会话的指令或草稿。子代理回报、任务通知和审批升级不等同于人类输入。

**审批升级**：权限请求转交用户处理的状态；不表示用户已经输入指令、接管代码或批准操作。

## 进展与交付

**主轮结束**：Claude 当前轮不再继续生成或调用工具。该事实不能证明其后台工作结束。

**阶段交付**：执行方针对约定子任务、里程碑或实现批次提交的结果与证据。

**稳定交付**：阶段交付对应的实际代码版本保持稳定，执行状态也满足进入审查的条件。

**业务验收**：主控根据目标、实际改动和检查证据作出的交付判断。主轮结束或阶段交付不自动构成业务验收。

**单会话时长上限**：用户主动为一个执行会话指定的最长执行预算；未指定时不限时。明确的审批等待和人类挂起不消耗执行预算，总持续时间和等待时间分别记录。
