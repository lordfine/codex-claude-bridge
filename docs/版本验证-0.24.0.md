## 能力限制

Claude CLI 显示低档和调用指定代理，并不能证明私人 GLM 网关遵守推理参数；仍标 providerVerification=unverified。既有会话不强制重启，无法安全应用时显示 pending_restart。Codex 正在执行的桌面轮不能即时改等级。

检查账本来自执行方声明，连接器核对源码和声明的环境、范围及命令；主控仍判断证据充分性。运行中的 Goal 不被擅自暂停，主控写入器长期占用仍可能延迟事件续接，不能把本次隔离无 Goal 验证外推为所有 Goal 流程已解决。

Mac 的模型与 Orca 实机链路本轮没有现场设备验证；跨平台 CI 覆盖不等同该实机证明。全部真实测试均为新会话，没有操作原 Forge UUID，也未复现共享 Orca 全应用重启。
