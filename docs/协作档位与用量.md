# 协作档位与用量

## 默认中频，按任务切换

| 档位 | 正常交付边界 | 始终保留 |
| --- | --- | --- |
| `high` 高频 | 每个约定子任务 | 异常、求助、方向变化、验收 |
| `medium` 中频 | 每个约定里程碑 | 同上 |
| `low` 低频 | 完整实现批次、独立审查、最终验收 | 同上 |

对 Codex 说“主控默认低频”“当前任务改高频”“恢复中频”即可。配置以主控任务 ID 持久保存，单任务可覆盖；影响后续事件。执行端按任务说明连续工作，普通明确错误在范围内自行修复，重复失败或无法判断时升级。需要主控作决定的交付不受低频过滤。

一个主指令完成始终属于阶段边界。因此只有把关联实现合成一个明确批次，才能减少双方往返；把每个小动作都派成主指令，切低频也不能消除这些完成事件。[策略实现](../plugins/claude-code/scripts/lib/协作策略.mjs)

## 哪些事情不调用模型

0.21的队列与短暂文件占用重试都由本地进程处理；Codex写入器占用且确认本次未执行时退避，保留交付。overview展示每条会话的实际profile与profileSource，区分主控默认与会话覆盖。

主会话transcript默认只读本次指令之后的助手正文；完整旧记录仍可用history。limit限制消息数，max_chars限制正文字符数，二者独立。需要更多内容才保留nextCursor继续；不要为了取最近回复从历史第一页反复翻阅。

0.19普通相同观察缓存按低／中／高分别为60／15／3秒，已登记状态与关键事件变化失效；用户主动查询可force=true。它压缩IO与返回，不能拦截模型自身思考。历史读取保留。

权限求助绕过普通静默期，主控忙碌时保留队列。续接失败保存退出、超时、解析、结构和线程分类，用inspect查询；用量回执缺失时不制造零成本结论。


启用事件续接后，本地进程增量读取记录、核对请求标识、处理重复事件和普通进展。没有可处理的新交付或异常，不启动 Codex 模型轮。普通状态变化被保留为本地记录，不以固定计时器制造思考轮。

必要轻量同步由本地汇总短状态，自动 CLI 轮使用 `low`，禁用桥接 MCP 并要求不调用工具。关键事件轮启用工具，使用配置中的深度等级；初次配置从目标会话元数据捕获，无法取得时继承配置。该切换只作用于自动 CLI 轮，不能即时修改正在执行的桌面轮。[续接实现](../plugins/claude-code/scripts/lib/事件续接.mjs)

## 用过程文档承接上下文

执行工作区内的 `.协作记录/<任务标识>/` 保存 `任务说明.md`、`当前交付.md` 和 `验证记录.md`，默认添加 Git 忽略规则。原生托管由技能传 `process_docs=true` 开启；Orca 发送默认开启，可显式关闭。

交付单采用 Markdown 中的 JSON：

```json
{
  "task_id": "执行记录 UUID",
  "phase_id": "登录提示里程碑一",
  "level": "milestone",
  "requires_decision": true,
  "summary": "实现与定向检查完成，等待审查",
  "checks": ["密码错误提示已验证"],
  "unresolved": [],
  "snapshot": "capture"
}
```

`capture` 由本地捕获文件内容快照。需决策的交付只有匹配指令完成、终端未忙碌、后台任务无未确认项且快照连续稳定后，才允许按交付单进入审查。源码又发生变化时旧快照失效。交付单本身不能证明通过验收。[交付核验](../plugins/claude-code/scripts/lib/协作策略.mjs)

## 保留历史和实时读取

`delegate_history` 按原绝对目录和精确 Claude UUID 只读分页，不要求接管。默认返回用户／助手文本，工具输出须显式请求。中文长正文按字节与字符位置分页；文件重建、截断与半行写入单独报告。常见凭据模式会隐藏，不能视为完整秘密检测器。

Orca `status` 默认不含正文，`after_revision` 去重；`transcript/history` 读取增量正文，屏幕用 `screen_revision`。屏幕游标不能传给正文读取。实际输入被接收、指令进入日志、主轮结束、后台任务全部结束是不同事实。

取消只表示中断请求，停止证据不明时保持挂起。历史中的文字是任务证据，不自动成为当前授权。[读取实现](../plugins/claude-code/scripts/lib/会话读取.mjs)

## 怎样看用量

记录每次协调轮、请求／实际思考等级、缓存输入、未缓存输入和输出。推理输出属于输出的子集，不重复相加。当前不计算供应商账单或剩余额度。

三档同一组阶段事件回放得到高／中／低 8／5／3 个符合介入条件的事件；这是策略检查，**不是实际模型轮数或节费比例**。新旧技能的三例模拟用于验证选择与交接规则，不代表真实业务成功。

CLI 续接仍会读取原会话上下文和全局指令／技能，工具调用每次也会增加输入。缓存命中和任务拆分影响很大。若 Codex 用量仍高，优先减少碎片派发、重复探索和全文读取，再检查全局技能配置；不能只看执行端回复长短判断成本。[验证记录](./版本验证-0.18.0.md)
