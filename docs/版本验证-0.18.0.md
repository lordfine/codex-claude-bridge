## 实机事件链路

隔离临时 Git 工作区，Claude Code 2.1.291、当前 `glm-5.3-flash` 配置、Orca 1.4.220。使用插件新建一个自己的 Orca Claude 窗口；未接入业务会话。

1. 对独立 Codex 种子会话配置续接，从元数据捕获原等级 `xhigh`。
2. 显式轻量同步：本地摘要 → Codex CLI → 实际等级 `low` → `handled` → 队列确认。
3. Claude 接收带唯一标识的最小指令，只回复“实机交付确认”；指令进入精确会话日志并完成。
4. 本地观察器触发完成事件，Codex CLI 实际等级恢复 `xhigh`，核对正文后返回 `handled`；待处理队列归零。
5. 停用自己的测试续接并关闭自己的测试终端。
