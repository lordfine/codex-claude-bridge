# 桥接复盘

用户在执行具体任务的 Codex 窗口调用本技能。目标是提供能追溯的改进依据，尽量让日志统计由本地程序完成。

## 执行

1. 使用当前 `CODEX_THREAD_ID`。用户明确指定其他主控时使用其精确 UUID，不猜最近会话。读取本技能路径后，将 `../../scripts/采集迭代证据.mjs` 解析为绝对路径。
2. 运行 `node "采集脚本的绝对路径"`。脚本从环境读取主控，定位桥接状态和关联 Claude 日志；无需启动 MCP、Claude、Codex CLI 或新的聊天。用户指定范围时传 `--起始`、`--截止`，值用含时区的 ISO 时间；指定主控时传 `--主控`。默认报告位于用户目录 `.cache/cc-plugin-codex/迭代复盘/`。
3. 只读取脚本返回的 `复盘报告.md`，需要解释异常时读取同目录 `证据包.json` 的汇总与来源指针。不要把整段聊天和工具输出载入上下文，不临时重写采集脚本。身份无法定位时请求精确主控 ID；没有日志时如实报告缺失，不转而扫描无关聊天。
4. 用短中文说明：测到了什么、最值得核对的异常、哪些数据未知。返回两个文件的绝对路径链接。告诉用户在插件开发窗口提供证据包路径即可继续迭代；本技能不会自动给该窗口发消息。

## 解释证据

- 采集脚本的 `modelCalls=0` 只表示统计过程不调用模型；运行此技能的 Codex 本轮仍有用量。
- 费用没有可靠账单时保持未知，不使用 token 大小替代费用结论。
- 工具输入输出字节不是 token；缓存输入与输出分别看。Claude 缓存写入、读取字段与 Codex 累计输入口径不同。
- “仅观察候选”依据工具白名单估计，不等同浪费。无工具推理不自动归为观察；不承诺能看到宿主不可访问的日志。
- 既有 Claude 会话在默认全会话范围可能包含接入前记录；比较同类任务时指定相同时间范围。子代理用量单独标出是否有覆盖。
- 处理回执、验收记录、业务验收通过是不同证据；未知的返工及人工介入次数不写成零。
- 不复制原始命令、聊天正文、凭据、完整路径与错误正文。采集只写新报告，不修改会话、队列、配置或业务文件，不上传文件。
